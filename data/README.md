# Data

The dataset is **not stored in this repository**. Download it from Kaggle:

**Loan Default Prediction Dataset** (nikhil1e9): https://www.kaggle.com/datasets/nikhil1e9/loan-default

- File: `Loan_default.csv`
- 255,347 rows, 18 columns
- Taken from Coursera's [Loan Default Prediction Challenge](https://www.coursera.org/projects/data-science-coding-challenge-loan-default-prediction)

Check the dataset's licence on the Kaggle page before reusing it.

Put the CSV in a folder SQL Server can read (for example `C:\sql\loan\`) and set that path in `sql/02_load_data.sql`.
